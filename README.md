# 🚀 Workshop Portofolio Frontend

Selamat datang di project workshop pembuatan website portofolio! Project ini didesain khusus untuk teman-teman mahasiswa baru yang baru mulai belajar *frontend development*.

Di sini kita akan belajar membuat website portofolio yang keren, modern, tapi dengan kode yang simpel dan mudah dipahami. 

## 🛠️ Teknologi yang Digunakan
Kita menggunakan alat-alat (*tools*) modern yang populer di dunia kerja, tapi tetap ramah untuk pemula:
- **React** & **Vite**: Untuk membangun antarmuka (*User Interface*) website agar cepat dan interaktif.
- **Tailwind CSS (v4)**: Untuk mendesain tampilan website dengan mudah (seperti warna, jarak, ukuran).
- **shadcn/ui**: Kumpulan komponen desain siap pakai (seperti tombol dan kartu) yang tampilannya sangat rapi.
- **Lucide React**: Kumpulan ikon-ikon menarik untuk mempercantik website.
- **React Bits**: Untuk menambahkan sedikit animasi kecil agar website terasa lebih hidup.

## 🎯 Tujuan Pembelajaran
Selama workshop ini, kita akan belajar bareng untuk:
1. Memahami cara kerja dasar React.
2. Menggunakan Tailwind CSS untuk menghias tampilan website.
3. Merangkai beberapa bagian kode menjadi satu halaman website utuh.
4. Membuat portofolio pertamamu untuk dipamerkan!

## 🚀 Cara Menjalankan Project
Untuk menjalankan project ini di laptopmu, ikuti langkah-langkah mudah berikut:

1. **Pastikan kamu sudah menginstal Node.js** di laptop.
2. Buka terminal (Command Prompt, PowerShell, atau terminal di VS Code) di folder project ini.
3. Ketik perintah berikut untuk mengunduh semua perlengkapan project, lalu tekan **Enter**:
   ```bash
   npm install
   ```
4. Setelah selesai (tunggu sampai proses *loading* berhenti), jalankan website-nya dengan perintah:
   ```bash
   npm run dev
   ```
5. Buka *browser* (Google Chrome, Edge, Safari, dll) dan buka *link* yang muncul di terminal (biasanya `http://localhost:5173`).

## 💡 Tips Belajar
- **Jangan takut salah!** Error adalah hal yang sangat wajar saat ngoding. Dari error, kita jadi lebih paham.
- **Eksplorasi aja:** Cobalah mengubah-ubah teks atau mengganti warna di dalam kode untuk melihat apa yang akan terjadi di website.
- **Tanya Kakak Asdos:** Kalau kebingungan atau menemukan masalah, jangan sungkan untuk mengangkat tangan dan bertanya selama acara berlangsung.

Semangat belajarnya dan selamat membangun website portofolio pertamamu! 🎉
